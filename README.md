# Alma de Hilo · tema de Shopify

Tema de la tienda **almadehilo.myshopify.com** (basado en Horizon), listo para la integración de Shopify con GitHub.

- La landing está en `sections/landing-alma-de-hilo.liquid` y la página de inicio la carga desde `templates/index.json`.
- Cada cambio que se guarda en la rama conectada se publica solo en el tema de Shopify, y los cambios hechos desde el editor de Shopify vuelven a esta rama.
- Para volver atrás: el historial de commits de GitHub tiene cada versión.
